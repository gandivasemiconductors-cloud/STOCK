# Sign Media Stock

A public inventory showcase for Signmedia Enterprises, featuring sample signage materials, low-stock alerts, stock adjustments, and activity history.

## Run

Open `index.html` in a modern browser. No build step is required. Sample data and edits are stored only in the current browser.

## Public demo notice

This site has no sign-in or user accounts. Do not enter real or confidential information. Visitors can edit sample data in their own browser; changes are not shared with others.

## GitHub Pages

Deployment is configured through the GitHub Actions workflow in `.github/workflows/pages.yml`. Enable GitHub Pages with GitHub Actions as the source in repository settings if necessary.
